Instruções do Exercício de Extração de Texto no Excel:

Objetivo: Praticar as funções ESQUERDA (LEFT), DIREITA (RIGHT) e EXT.TEXTO (MID).

Passo a Passo:
1. Abra o Excel e importe este arquivo de texto (Guia Dados > De Texto/CSV).
2. O delimitador dos dados é o Ponto e Vírgula (;).
3. Na coluna ao lado dos dados, crie uma coluna chamada "Categoria". Use a função =ESQUERDA(A2; 3) para extrair as 3 primeiras letras do código.
4. Crie uma coluna chamada "Ano". Use a função =EXT.TEXTO(A2; 5; 4) para extrair o ano de fabricação.
5. Crie uma coluna chamada "Lote". Use a função =DIREITA(A2; 4) para extrair os 4 últimos caracteres do código.
